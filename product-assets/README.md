# Product assets

Каноническое хранилище изображений товаров.

```text
product-assets/
├── cards/<sku>/
│   ├── compatibility.jpg  # слайд совместимости
│   └── info.jpg           # информационный слайд
├── sources/<sku>/
│   ├── 01.jpg             # исходные фото по порядку
│   └── 02.jpg
├── shared/                 # общие слайды без товарного артикула
└── manifest.csv            # полный проверяемый индекс
```

Правила:

- артикулы и расширения приводятся к нижнему регистру;
- один каталог соответствует одному артикулу;
- роли карточек имеют стабильные имена `compatibility.jpg` и `info.jpg`;
- исходники нумеруются с `01` в исходном порядке;
- точные повторы из временных партий не сохраняются;
- `manifest.csv` содержит роль, путь, разрешение, размер и SHA-256 каждого файла.

Повторная индексация и импорт выполняются скриптом `tools/normalize_product_assets.ps1`.
